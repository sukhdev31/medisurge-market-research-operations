# Your first 15 minutes

1. Extract the ZIP. Open the inner `medisurge-market-ops` folder in VS Code.
2. Open **Terminal** and run the three PowerShell commands under **Start in VS Code** in `README.md`.
3. Open the address printed by Streamlit, usually `http://localhost:8501`.
4. Click **Account priorities**, change **Weight preset** to **Expansion led**, and inspect one account's six reasons.
5. Click **Market scenarios**, move **Serviceable share**, and watch SAM/SOM change.
6. Click **Evidence & briefs**. The fictional accounts have no verified facts, which is intentional.
7. Open the Excel workbook and the review deck from their respective folders.
8. Run the eight tests and the release check. Create an empty GitHub repo under `sukhdev31`; use the exact `git` commands in README.

**Explain it in one sentence:** “I built a hospital opportunity research system for Medisurge that exposes the scoring logic, market assumptions and source quality, so a decision owner can review a priority before outreach.”

**What to say about impact:** “This is a reproducible public prototype with 180 fictional accounts. The business pilot and actual time saved are still to be measured.”
